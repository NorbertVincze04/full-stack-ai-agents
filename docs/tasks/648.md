## Description
create an always visible calendar on home page where users can select a date to book a desk. users aren't allowed to pick past date or days from weekend. only the current and next 3 available days can be booked. the selected date is written in the left side of a top-bar that you will also have to create. in the right side of the top bar is going to be a button called 'Book Now', which clicked turns into 'withdraw booking' and saves the book date for the user that selected the date. only logged in users can book a date. if someone isn't logged in and try to click 'book now' it gets an error saying 'you most log in first'. on 'withdraw booking' the booked date is deleted from the users info.

## Acceptance Criteria
logged in users can select a date and book it
