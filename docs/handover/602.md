## Summary
The Angular app shell (`AppComponent`) now renders a `<footer>` with `© <current year> Desk Booking. All rights reserved.` after `<main>` and outside `<router-outlet />`. The host is a column flex container with `main { flex: 1 }`, so the footer is intended to sit at the viewport bottom on short pages and below the content on long pages. The year is computed at runtime. No backend, API or database changes.

## What was implemented

### Frontend
- `app.component.html`: `<footer>© {{ currentYear }} Desk Booking. All rights reserved.</footer>` after `<main>`.
- `app.component.ts`: `readonly currentYear = new Date().getFullYear()`.
- `app.component.css`: `:host` column flex with `min-height: 100vh` and `100dvh` override; `main { flex: 1 }`; footer full width, centred, padding `1rem`, `overflow-wrap: anywhere`, `#1f2937` background with `#ffffff` text (about 14:1 contrast).
- `styles.css`: `html, body { margin: 0; }` (added in fix iteration 1 to remove the 8px default body margin that caused overflow and an inset footer).
- `app.component.spec.ts`: test `should render the copyright footer`.
