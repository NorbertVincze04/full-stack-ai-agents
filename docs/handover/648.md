## Summary
`/` now shows an always-visible month calendar and, below the header, a top bar: the selected date on the left (`Mon, 9 Nov 2026`) and a `Book Now` / `Withdraw booking` button on the right. Only 4 weekdays from today (or the next weekday) are selectable. Anonymous clicks show `You must log in first`. Bookings are stored per user id (never the e-mail) through new JWT-protected endpoints.
