# Handover - task 601: initialize frontend (Angular 18) and backend (Node.js)

- Source: Azure DevOps, project `WebTools`, work item 601
- Final status: `done` (see "Accepted risk")

## Summary
`Frontend/` is now an Angular 18 NgModule app and `Backend/` is a Node.js + TypeScript (ESM) + Express 5 project. `ng serve` / `npm start` serves the frontend on port 4200. The backend prints `hello world` on startup. No endpoints, database, auth or frontend-to-backend integration exist (out of scope).

## What was implemented

### Frontend
- Angular 18.2 workspace generated with `ng new --no-standalone --routing --style=css --ssr=false --prefix=app`; `AppModule` + `AppRoutingModule` (empty routes).
- `npm start` = `ng serve`; `npm run build`; `npm test`; `npm run test:ci` (headless).
- Template reduced to `<main><h1>{{ title }}</h1><router-outlet /></main>`, title `Desk Booking`; `<noscript>` fallback in `index.html`.
- `engines.node` `>=22.18`; `.editorconfig` generated.

### Backend
- `src/app.ts`: `createApp()` Express factory (`cors` with `CORS_ORIGIN`, default `http://localhost:4200`; `express.json()`).
- `src/server.ts`: loads `dotenv`, listens on `PORT` (default 3000), logs exactly `hello world`.
- Scripts: `start` (`node src/server.ts`), `dev` (`tsx watch src/server.ts`), `build` (`tsc` -> `dist/`).
- `tests/app.test.ts` and `tests/server.test.ts` (10 `node:test` tests, added by the backend tester).
- `.env.example` with `PORT`, `CORS_ORIGIN`.

## Accepted risk (human decision)
- **H1 (high, frontend security)**: `npm audit --omit=dev` reports 8 vulnerabilities (4 moderate, 4 high) in Angular 18.2.14 runtime packages (`<=19.2.25`; XSS/sanitisation bypasses, `HttpClient` XSRF leakage, `HttpTransferCache`, hydration, `formatDate` DoS). The only fix is a breaking upgrade to Angular 22.x, which is outside the spec's Angular 18 pin (F1, AC1). The scaffold has no i18n, `HttpClient`, SSR/hydration, SVG bindings or user input, so it is not exploitable as shipped (confirmed by the security reviewer).
- **Status: explicitly ACCEPTED by the human** for the no-feature baseline. It is not treated as blocking `done`. The acceptance was given in the task request; it is not recorded elsewhere in `docs/`.
- **Condition**: no feature work (booking UI, `HttpClient`, forms, SSR) on Angular 18 until the upgrade follow-up is done.
